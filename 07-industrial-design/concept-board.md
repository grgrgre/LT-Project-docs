## Included Products

| Product | Visual Direction |
| --- | --- |
| LT Mini | Compact MVP handheld with LCD, joystick, LoRa, USB-C, and expansion direction. |
| LT Core | Larger flagship handheld with joystick, larger display, internal expansion, and optional keyboard-module direction. |
| LT Core Pro | Future higher-end Core variant with compute-module, Linux, compact keyboard workflow, dock, and shared-bus direction. |
| QWERTY Input Module | External keyboard module direction for terminal and command workflows. |

## Rules

- Treat this board as a communication tool, not manufacturing data.
- Validate real dimensions before PCB or enclosure work.
- Keep LT Mini visually simple and MVP-focused.
- Keep LT Core Pro as an extension of LT Core, not a separate ecosystem.
- Treat QWERTY as a module-first input system unless a later product decision
  explicitly makes it built in.
