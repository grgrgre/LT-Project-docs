# Naming

This file defines product naming rules for the LT Ecosystem.

## Rules

- Use `LT` as the ecosystem prefix.
- Use short product names.
- Product names should describe the role of the device.
- Avoid names that lock the hardware to one chip or one temporary feature.
- Keep future Pro versions compatible with the base name.

## Product Names

| Name | Type | Meaning |
| --- | --- | --- |
| LT Mini | Main product | Small ESP32-S3 handheld for learning and portable utilities. |
| LT Core | Main product | Flagship portable computer platform. |
| LT Core Pro | Future product | Higher-end LT Core variant. |
| LT Dock | Future product | Desktop, bench, power, or I/O accessory. |
| LT Relay | Future product | Expansion device for radio, network, or automation workflows. |
| LT Extreme | Future concept | Rugged or high-capability experimental variant. |

## Naming Notes

`LT Mini` should not be treated as a weaker LT Core. It is a focused small
platform with its own constraints.

`LT Core` should remain broad enough to support future compute changes, including
Linux-capable versions.
